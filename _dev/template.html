How a project runs.

The same six steps whether it is a landing page or a platform. Written, staged, and measured before it is called done.

  1. 01

    Brief

    A written brief and my questions back. Goals and content before layout, in writing, so decisions stay documented for your team.

  2. 02

    Structure

    Flows, page list and what each screen must do. For Arabic products this is where right-to-left is decided, not patched in later.

  3. 03

    First screen

    One screen designed and agreed before the rest exists. If the direction is wrong it costs a day, not a project.

  4. 04

    Build

    Hand-written, delivered in reviewable stages. Design and code come from the same person, so nothing is lost in a handover.

  5. 05

    Measure

    PageSpeed on both devices, accessibility checks, and a pass at 375 px before anything is called finished.

  6. 06

    Keep it running

    Most of my work lands in systems that already run. I read the existing code before I change it, and keep what works.
